# Проект «Мини-Склад»

Учебная конфигурация на платформе «1С:Предприятие 8.3» с минимальным контуром учёта (по главам 1–5).

## Что внутри

* **Справочники**: `Товары`, `Контрагенты`.
* **Документы**: `Поступление`, `Реализация` (базовые формы и движения).
* **Регистры**: `ОстаткиТоваров` (регистр накопления).
* **Интерфейс**: Подсистема `Мини-Склад` с выводом команд на панель.

## Как запустить / развернуть проект

1. Создайте пустую информационную базу 1С.
2. Откройте её в режиме **Конфигуратор**.
3. В верхнем меню выберите: **Конфигурация** -> **Загрузить конфигурацию из файлов...**
4. Укажите папку `src` из данного репозитория.
5. Обновите конфигурацию базы данных (нажмите клавишу `F7`).
