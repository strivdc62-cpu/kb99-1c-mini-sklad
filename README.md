# Проект «Мини-Склад»

Учебная конфигурация на платформе «1С:Предприятие 8.3» (по главам 1–5).

## Что внутри
* Справочники: `Номенклатура`, `Контрагенты`.
* Документы: `ПоступлениеТоваров`, `РеализацияТоваров`.
* Регистры: `ОстаткиТоваров`.
* Интерфейс: Подсистема `МиниСклад`.

## Как запустить / развернуть проект
1. Создайте пустую информационную базу 1С.
2. Откройте её в режиме **Конфигуратор**.
3. Выберите: **Конфигурация** -> **Загрузить конфигурацию из файлов...**
4. Укажите папку `src` из этого репозитория.
5. Обновите конфигурацию базы данных (клавиша `F7`).
